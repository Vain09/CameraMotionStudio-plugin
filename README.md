# CameraMotion Studio (plugin downloads)

Bouncing, orbiting and tracking cameras for FFXIV GPose, with sliders for intensity and position.

Install in game:
1. `/xlsettings` > **Experimental** > **Custom Plugin Repositories**: add
   `https://raw.githubusercontent.com/Vain09/CameraMotionStudio-plugin/main/repo.json`, tick it, **Save**.
2. `/xlplugins`, search **CameraMotion Studio**, install, open with `/cammotion`.

The camera only moves while GPose is open. No game files are changed, and nothing is sent to the server.
